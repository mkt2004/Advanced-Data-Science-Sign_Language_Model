# Advanced Data Science - Sign Language Model Instructions
Group 1 Advanced Data Science Image processing model to detect sign language characters

========================


# IMPORTANT


========================

This project was made in googleColab and intended to be ran in a googleColab environment.

To run elsewhere, directory pathing may need to be edited at top of .ipynb file, after imports; additionally, importation of googleDrive drive may not be needed 


========================




For proper compilation:
------------------------
Download folders:
- sign_mnist_test
- sign_mnist_train

Download files:
- sign_mnist_test.csv
- sign_mnist_train.csv

Create a folder named "SignLanguageDataset" within your own personal "My Drive" in googleDrive 
Place all Downloaded folders and Files in your "SignLanguageDataset"

Upload or open .ipynb file in a new googleColab notebook

After googleDrive is connected to googleColab notebook, SignLanguageModel should be fully compilable!
Compile with "Run all" at top of your notebook, or start each cell individually with their play buttons at the side
***** Code may fail if each cell is not ran sequentially
------------------------
